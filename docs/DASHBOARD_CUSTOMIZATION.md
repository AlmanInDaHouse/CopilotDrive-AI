# Personalización en laboratorio

1. Pulsa **Personalizar** en el dashboard. Activa **modo laboratorio** y confirma
   explícitamente que el dispositivo está en un **entorno de prueba detenido**.
   Esa declaración no verifica aparcamiento. Si hay movimiento, no se permite entrar.
2. Elige preset o añade tarjetas. Usa **Subir/Bajar**, tamaño y **Ocultar/Mostrar**.
   No se permiten tipos duplicados ni ocultar la última tarjeta visible.
3. **Vista previa** muestra el borrador con datos de las fuentes existentes. No
   inicia búsquedas ni acciones de las tarjetas. La barra fija de Jarvis sigue accesible.
4. **Guardar** persiste; **Cancelar** o Atrás descarta. **Restaurar distribución
   predeterminada** cambia el borrador a Classic; hay que guardar para aplicarlo.
5. **Revocar laboratorio y salir**, movimiento, pérdida de conexión real, caducidad
   a los 120 s o segundo plano descartan el editor y requieren nueva confirmación.

Presets: Classic (vehículo/audio/navegación/Jarvis), Driver (vehículo destacado,
navegación/reloj), Media (audio destacado/navegación/Jarvis) y Laboratory
(OBD/sistema/vehículo/Jarvis). No alteran permisos, servicios ni proveedores.

Compacta ocupa una columna, expandida dos, panorámica cuatro donde se admite.
Pantallas pequeñas y fuentes ampliadas proyectan el diseño a menos columnas;
el layout guardado conserva su forma canónica. Desplaza la lista si falta espacio.
La barra inferior conserva PTT, ajustes, micrófono y origen de datos. Pulsa el
estado/respuesta de Jarvis para leer el texto completo aunque su tarjeta esté oculta.

El diseño sobrevive al reinicio; borradores y confirmación de laboratorio no.
JSON inválido recupera Classic con aviso. Si guardar falla, reintenta o cancela;
el diseño anterior continúa vigente. No hay soporte Android Auto, AAOS ni CarPlay.
