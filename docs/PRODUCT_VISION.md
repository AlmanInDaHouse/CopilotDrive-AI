# Visión de producto
CopilotDrive-AI es un asistente instalable para Android abierto, con dashboard legible, consultas por voz,
multimedia autorizada y navegación delegada. Objetivo inmediato: demo de laboratorio verificable sin coche,
servidor ni claves. No es sistema de seguridad ni producto homologado.

La UI y la voz distinguen simulación, sensor ausente, dato caducado y desconexión. El modelo es opcional;
las acciones se validan de forma determinista. Sin audio ni conversaciones persistentes. Estado de movimiento
desconocido por defecto; configuración solo en entorno de prueba detenido confirmado por el usuario, sin
convertir esa declaración en una lectura de vehículo estacionado.

Aceptación y alcance por módulo en specs/. El APK debug es para revisión, no distribución de producción.
