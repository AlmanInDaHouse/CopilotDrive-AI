# Sprint 4 — validación física (borrador)

Objetivo: medir interoperabilidad y seguridad de las integraciones ya implementadas antes de añadir funciones de conducción. Prioridad 1: OBD Bluetooth Classic en banco y vehículo detenido; prioridad 2: STT/TTS y audio focus en teléfonos reales; prioridad 3: proveedor Chat Completions real con texto consentido. La primera prioridad determina si Sprint 3 puede declararse compatible con adaptadores concretos.

No se añade escritura ECU, comandos ELM/CAN libres, BLE genérico, telemetría remota, VIN persistente ni automatización mientras se conduce. La app sigue funcionando sin hardware ni clave. Este documento no supone que haya dispositivos o credenciales disponibles.
